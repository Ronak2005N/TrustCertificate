# Certiproof

Certificate verification you can trust. Issue digitally signed certificates anchored on blockchain and verify authenticity in seconds with cryptographic proof.

## Development

Requires Node.js and a package manager (this repo uses [bun](https://bun.sh)).

```sh
bun install
bun run dev
```

The dev server runs at `http://localhost:8080`.

## Scripts

- `bun run dev` — start the Vite dev server
- `bun run build` — production build (Nitro/Cloudflare target)
- `bun run preview` — preview the production build
- `bun run lint` — ESLint
- `bun run format` — Prettier
